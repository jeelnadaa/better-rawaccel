Got Questions?

Frequently Asked Questions

Will I get banned in Valorant by Riot Vanguard? +
No. Raw Accel has been officially reviewed and whitelisted by Riot Vanguard, Easy Anti-Cheat, and BattlEye. It is a certified kernel-level mouse filter driver that modifies raw input coordinates using pure math. It does not inject into game memory, read screen pixels, or simulate automated macros.
How is this different from the original Raw Accel GUI? +
accel. (Better Raw Accel) is a complete modern rewrite. It features 14 engineering themes, a built-in cm/360 and cross-game sensitivity converter, speed histograms, reference curve pinning for A/B testing, interactive LUT point dragging, profile shortcode sharing (RA1:...), and a full Model Context Protocol (MCP) server for AI assistants.
Does accel. need to stay open while I play? +
No. Once you click "Write to driver" (Ctrl+Enter), your settings are written directly to the kernel driver. You can close the application completely, and acceleration will remain active in all games. If you check "Start with Windows" in the Driver settings, settings apply at logon automatically without opening the window.
How do I uninstall if I ever want to revert? +
Simply run uninstaller.exe (located in the same folder) as Administrator, and restart your PC. Your mouse input will immediately return to standard raw Windows input.
How do I use the in-game HUD overlay and hotkeys? +
Press Ctrl+Alt+O from anywhere (in-game or on desktop) to toggle the floating HUD showing your active profile, mouse device, and cm/360. Cycle through profiles on the fly with Ctrl+Alt+P or switch directly to slots 1–5 with Ctrl+Alt+1..5. The overlay is 100% external with click-through and zero DLL injection, safe with Vanguard and VAC.
How do I connect Claude Code, Cursor, or VS Code over MCP? +
accel. hosts a local HTTP MCP server on port 47700. Simply add {"mcpServers": {"accel": {"url": "http://127.0.0.1:47700/mcp"}}} to your Claude Desktop or Cursor configuration. Read our MCP Connection Guide for complete details.
